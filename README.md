# Customer Transaction RPA Bot

A Python-based Robotic Process Automation (RPA) pipeline that processes customer transaction data from Excel files, identifies top customers by total transaction value, and automatically emails the report.

> ⚠️ **This is an ongoing project.** See the [Roadmap](#-roadmap--planned-features) section for planned features and known limitations.

---

## 📁 Project Structure

```
rpa_project/
├── data_generator.py   # Generates sample input Excel files
├── processor.py        # Core ETL pipeline — cleans, aggregates, reports
├── mailer.py           # Sends the report via email (SMTP)
├── transactions.xlsx   # Generated by data_generator.py (input)
├── companies.xlsx      # Generated by data_generator.py (input)
└── output.xlsx         # Generated by processor.py (final report)
```

---

## ⚙️ How It Works

```
transactions.xlsx ──┐
                    ├──► processor.py ──► output.xlsx ──► mailer.py ──► 📧 Email
companies.xlsx ─────┘
```

1. **`data_generator.py`** — Creates two Excel input files with realistic fake data (transactions + company names)
2. **`processor.py`** — Loads, cleans, aggregates, and enriches the data; saves the Top 10 customers to `output.xlsx`
3. **`mailer.py`** — Attaches `output.xlsx` to an email and sends it via SMTP

## 🚀 Quickstart

### 1. Install dependencies

```bash
pip install pandas openpyxl
```

### 2. Configure email credentials

Open `mailer.py` and fill in your details:

```python
EMAIL_ADDRESS  = "yourname@wp.pl"        # your sending email
EMAIL_PASSWORD = "your_password"         # your email password
RECEIVER_EMAIL = "recipient@example.com" # who receives the report
SMTP_HOST      = "smtp.wp.pl"            # adjust to your provider
```

> **Gmail users:** You must use an [App Password](https://myaccount.google.com/apppasswords), not your regular password. Go to Google Account → Security → 2-Step Verification → App Passwords.

Supported providers out of the box:

| Provider | `SMTP_HOST` | `SMTP_PORT` |
|---|---|---|
| Gmail | `smtp.gmail.com` | `587` |
| Outlook/Hotmail | `smtp.office365.com` | `587` |
| WP.pl | `smtp.wp.pl` | `587` |
| Onet.pl | `smtp.poczta.onet.pl` | `587` |
| Interia.pl | `poczta.interia.pl` | `587` |

### 3. Enable the mailer in `processor.py`

At the bottom of `processor.py`, uncomment the two lines:

```python
if __name__ == "__main__":
    run_pipeline()

    # Uncomment to also send the report by email:
    from mailer import send_report
    send_report(attachment_path="output.xlsx")
```

### 4. Run

```bash
# Option A — step by step
python data_generator.py   # create input files
python processor.py        # process data + send email

# Option B — use your own real Excel files (see below)
```

## 📂 Using Your Own Excel Files

Instead of the generated sample data, you can drop in your own files.

Your `transactions.xlsx` must have these columns:

| Column | Type | Description |
|---|---|---|
| `nip` | string | 10-digit tax ID |
| `price` | float | transaction value |
| `date` | date | transaction date |

Your `companies.xlsx` must have:

| Column | Type | Description |
|---|---|---|
| `nip` | string | 10-digit tax ID |
| `company_name` | string | company display name |

Place both files in the same folder as the scripts, then run:

```bash
python processor.py
```

No changes to the code required.

## ⚠️ Known Limitations

- Email credentials are currently stored as plain text in `mailer.py` — use a `.env` file or environment variables in production
- The bot does not deduplicate transactions (same NIP + same date + same price is treated as a separate transaction)
- Only `.xlsx` format is supported as input (not `.csv` or `.xls`)
